## ✨ Features

- **Responsive Design** — Mobile-friendly layout that works across all screen sizes
- **Home Section** — Introduction and quick navigation to key sections
- **About Section** — Background, interests, and skill highlights
- **Projects Showcase** — A dedicated page displaying software development projects
- **Contact Page** — Easy way to reach out for collaborations or opportunities

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- (Optional) [Node.js](https://nodejs.org/) if running a local dev server

### Run Locally

```bash
# Clone the repository
git clone https://github.com/Althaf-CH/Personal-portfolio-website.git

# Navigate into the project folder
cd Personal-portfolio-website

# Open index.html in your browser, or use a live server
# With VS Code Live Server extension:
#   Right-click index.html → "Open with Live Server"
```
